## Methodology (uniform across all 43)
- 10-year scenario DCF, weights bear 25% / base 50% / bull 25%.
- Scenario discount rates: base = 9% (stable compounder) / 10% (standard) / 12% (speculative) / higher where justified; bear = base + 250bp; bull = base − 150bp (floor 8%).
- Terminal growth ≤ 2.5% on year-10 FCF at **normalized mid-cycle margins** (never peak). TV > 70% of EV → haircut + disclose.
- Bear must hurt (≥2 of: revenue decline or <3% CAGR; ≥300bp margin compression vs base; ≥25% terminal derating) and bear FV must sit below current price.
- No management anchoring; bull gets genuine upside but same terminal discipline. Fair value = weighted DCF; departures need written falsifiable justification.
